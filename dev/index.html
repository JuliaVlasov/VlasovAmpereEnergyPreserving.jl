VlasovAmpereEnergyPreserving.jl

This package explores energy-preserving semi-Lagrangian methods for kinetic plasma simulations. The examples correspond to the numerical tests in Section 6 of Crouseilles, Liu and Yue, Semi-Lagrangian SAV method for Vlasov-Maxwell equations:

  • Two-stream instability: Vlasov–Ampère, Section 6.1.
  • Weibel instability: Vlasov–Maxwell, Section 6.2.
  • Landau–Weibel instability: Vlasov–Maxwell, Section 6.3.

Section 6.4 benchmarks a separate JAX implementation using the Weibel and Landau–Weibel cases; it does not introduce another initial condition. See the JAX acceleration benchmark for the benchmark setup and its relationship to these Julia examples.

Installation

Install Julia (version 1.11 or later is recommended), then clone the repository and instantiate its dependencies:

git clone https://github.com/JuliaVlasov/VlasovAmpereEnergyPreserving.jl.git
cd VlasovAmpereEnergyPreserving.jl
julia --project -e 'using Pkg; Pkg.instantiate()'

Run the commands on the individual case pages from the repository root.

Numerical method

The paper introduces scalar auxiliary variables (SAVs) for electric-field energy and splits the kinetic and field evolution into simpler subproblems. Spatial transport is treated with a Fourier spectral method; velocity transport uses a semi-Lagrangian method with high-order Lagrange interpolation. The splitting is designed to preserve Gauss's law and a modified total energy. Finite grids, velocity truncation and interpolation can affect those invariants in a numerical run. The two-stream example uses a symmetric splitting, while the Vlasov–Maxwell examples use the first-order Lie splitting.

Splitting operators and diagnostics

The docstrings below describe the subsystems, discretizations, and in-place updates used by the Julia implementation. For the one-space, two-velocity operators, f is indexed as (vx, vy, x); fields and SAV profiles are spatial vectors, and rx, ry are scalar auxiliary variables.

VlasovAmpereEnergyPreserving.solve! — Function
solve!(f, Ex, Ey, hf::OperatorHF, dt)

Advance free streaming and its electric-current coupling:

\[\begin{aligned} \partial_t f+v_x\partial_xf &= 0,\\ \partial_t E_x &= -J_x,\qquad \partial_t E_y=-J_y,\\ \partial_t B = \dot r_x = \dot r_y &= 0. \end{aligned}\]

Here $J_\alpha=\int v_\alpha f\,dv_x\,dv_y$. Free streaming is exact for each resolved spatial Fourier mode:

\[\widehat f^{\,n+1}(k,v_x,v_y) =e^{-ikv_x\Delta t}\widehat f^{\,n}(k,v_x,v_y).\]

For nonzero $k$, the field increments are computed from $(\widehat\rho^{\,n+1}-\widehat\rho^{\,n})/(ik)$ and $(\widehat q^{\,n+1}-\widehat q^{\,n})/(ik)$, respectively, where $\rho=\int f\,dv_x\,dv_y$ and $q=\int(v_y/v_x)f\,dv_x\,dv_y$. The velocity nodes must therefore have nonzero vx. Both electric-field zero modes are set to zero.

Update f, Ex, and Ey in place. f has dimensions (nvx, nvy, nx); fields are vectors of length nx.

solve!(f, Ey, B, hb::OperatorHB, dt)

Advance the magnetic splitting subsystem by dt:

\[\begin{aligned} \partial_t f + B\left(v_y\partial_{v_x}f-v_x\partial_{v_y}f\right) &= 0,\\ \partial_t E_y &= -\partial_x B,\\ \partial_t B = \dot r_x = \dot r_y &= 0. \end{aligned}\]

Here f[i, j, l] represents $f(v_{x,i}, v_{y,j}, x_l)$. At each spatial node, the velocity rotation is decomposed into three Fourier shears with coefficients $\tan(B\Delta t/2)$, $-\sin(B\Delta t)$, and $\tan(B\Delta t/2)$. The electric-field update uses a periodic Fourier derivative. B is unchanged.

The transported distribution is stored in hb.ft; this method does not copy it back to f. Ey is updated in place and returned.

source
solve!(f, rx, ry, B, gx, gy, he::OperatorHE, dt; interpolate=semilag_d2)

Advance the electric SAV splitting subsystem with fixed profiles gx, gy:

\[\begin{aligned} \partial_t f + r_xg_x\partial_{v_x}f + r_yg_y\partial_{v_y}f &= 0,\\ \partial_t B &= -\partial_x(r_yg_y),\\ \dot r_x &= -\frac12\int g_xJ_x\,dx,\\ \dot r_y &= -\frac12\int g_y(J_y+\partial_x B)\,dx. \end{aligned}\]

The scalar auxiliary variables (SAVs) are rx, ry. The velocity moments are $\rho=\int f\,dv_x\,dv_y$ and $J_\alpha=\int v_\alpha f\,dv_x\,dv_y$ for $\alpha\in\{x,y\}$, approximated by uniform-grid sums.

Use the midpoint accelerations $\overline E_\alpha=\tfrac12(r_\alpha^{n+1}+r_\alpha^n)g_\alpha$ to translate f in each velocity direction. interpolate(u, speed, dt, dv) performs each one-dimensional semi-Lagrangian translation. Spatial derivatives are periodic Fourier derivatives.

Update f and B in place and return (rxnp1, rynp1). The supplied profiles are unchanged; the electric-field arrays belonging to other splitting subsystems are not advanced here.

source
solve!(f::AbstractArray{T,3}, hf::OperatorLapentaHF, dt::Real) where {T}

Advance free streaming, leaving all fields fixed:

\[\partial_t f+v_x\partial_x f=0,\qquad \partial_t E_x=\partial_t E_y=\partial_t B=0.\]

For each velocity pair, apply the exact spatial Fourier multiplier $e^{-ikv_x\Delta t}$ on the periodic mesh. Update f, with dimensions (nvx, nvy, nx), in place and return nothing.

source
solve!(f, Ex, Ey, he::OperatorLapentaHE, dt)

Advance the electric acceleration and current subsystem:

\[\begin{aligned} \partial_t f+E_x\partial_{v_x}f+E_y\partial_{v_y}f &= 0,\\ \partial_t E_x &= -J_x,\qquad \partial_t E_y=-J_y,\\ \partial_t B &= 0. \end{aligned}\]

The moments are $\rho=\int f\,dv_x\,dv_y$ and $J_\alpha=\int v_\alpha f\,dv_x\,dv_y$. The field midpoint used for semi-Lagrangian translation in each velocity direction is

\[\overline E_\alpha =\frac{E_\alpha^n-\frac{\Delta t}{2}J_\alpha^n} {1+\frac{\Delta t^2}{4}\rho^n}, \qquad E_\alpha^{n+1}=2\overline E_\alpha-E_\alpha^n.\]

he stores the moment and interpolation work arrays. Update f, Ex, and Ey in place and return nothing.

source
solve!(f, Ex, Ey, B, hb::OperatorLapentaHB, dt)

Advance magnetic rotation and the source-free Maxwell subsystem:

\[\begin{aligned} \partial_t f+B\left(v_y\partial_{v_x}f-v_x\partial_{v_y}f\right) &= 0,\\ \partial_t E_y &= -\partial_x B,\qquad \partial_t B=-\partial_x E_y,\\ \partial_t E_x &= 0. \end{aligned}\]

Integrate the field equations by implicit midpoint in spatial Fourier space. Rotate velocities with three Fourier shears, holding the magnetic field at $\overline B=\tfrac12(B^{n+1}+B^n)$ during the rotation. Spatial and velocity directions use periodic Fourier transforms.

Update f, Ey, and B in place; Ex is unchanged. Return nothing.

source
solve!(f, Ex, Ey, gx, gy, rx, ry, he2, dt)

Advance the electric SAV subsystem without magnetic-field coupling:

\[\begin{aligned} \partial_t f+r_xg_x\partial_{v_x}f+r_yg_y\partial_{v_y}f &= 0,\\ \dot r_x &= -\frac12\int g_xJ_x\,dx,\qquad \dot r_y=-\frac12\int g_yJ_y\,dx,\\ \partial_t E_x = \partial_t E_y = \partial_t B &= 0. \end{aligned}\]

Here $J_\alpha=\int v_\alpha f\,dv_x\,dv_y$. he2 supplies the mesh. First recompute gx and gy from the fixed fields and auxiliary scalars with updateg!. Translate f in both velocity directions using $\overline E_\alpha=\tfrac12(r_\alpha^{n+1}+r_\alpha^n)g_\alpha$ and second-degree semi-Lagrangian interpolation.

Update f, gx, and gy in place and return (rxnp1, rynp1). Ex and Ey are unchanged.

source
solve!(f, Ey, B, gx, gy, rx, ry, hb2::OperatorHB2, dt)

Advance the magnetic SAV subsystem with fixed profile gy:

\[\begin{aligned} \partial_t f+B\left(v_y\partial_{v_x}f-v_x\partial_{v_y}f\right) &= 0,\\ \partial_t B &= -r_y\partial_x g_y,\qquad \partial_t E_y=-\partial_x B,\\ \dot r_y &= -\frac12\int g_y\partial_xB\,dx =\frac12\int B\partial_xg_y\,dx,\\ \dot r_x &= 0. \end{aligned}\]

The integration-by-parts identity assumes periodic spatial boundaries. Use centered periodic differences for the spatial derivatives and midpoint values of ry and B for the coupled update. Rotate velocities with three Fourier shears using the midpoint magnetic field.

Update f, Ey, and B in place and return (rx, rynp1). gx, gy, and rx are unchanged.

VlasovAmpereEnergyPreserving.HE! — Function
HE!(f, r, v, g, nv, kv, dv, nx, dx, dt; interpolate=semilag_d2)

Advance the one-velocity electric SAV subsystem with fixed profile g:

\[\partial_t f+rg\,\partial_vf=0,\qquad \dot r=-\frac12\int gJ\,dx,\qquad J=\int vf\,dv.\]

Approximate velocity and spatial integrals by uniform-grid sums. Use the midpoint acceleration $\overline E=\tfrac12(r^{n+1}+r^n)g$ to translate each column of f with interpolate(u, speed, dt, dv). f has dimensions (nv, nx) and is updated in place. Return the new auxiliary scalar; g is unchanged.

source
VlasovAmpereEnergyPreserving.hf! — Function
hf!(f, E, dt, dv, v, kx)

Advance one-velocity free streaming and its electric-current coupling:

\[\partial_t f+v\partial_xf=0,\qquad \partial_t E=-J,\qquad J=\int vf\,dv.\]

Apply $e^{-ikv\Delta t}$ in spatial Fourier space and update the nonzero field modes using $\widehat E^{\,n+1}=\widehat E^{\,n} +(\widehat\rho^{\,n+1}-\widehat\rho^{\,n})/(ik)$, where $\rho=\int f\,dv$ is approximated by a velocity sum times dv. Set the field zero mode to zero.

Update f, of size (length(v), length(kx)), and E in place; return E.

source
VlasovAmpereEnergyPreserving.HE_lapenta! — Function
HE_lapenta!(f, E, v, nv, kv, dv, nx, dx, dt)

Advance the one-velocity electric acceleration and current subsystem:

\[\partial_t f+E\partial_vf=0,\qquad \partial_t E=-J,\qquad \rho=\int f\,dv,\quad J=\int vf\,dv.\]

Use uniform-grid velocity moments and the midpoint field

\[\overline E=\frac{E^n-\frac{\Delta t}{2}J^n} {1+\frac{\Delta t^2}{4}\rho^n}, \qquad E^{n+1}=E^n-\Delta t\left(J^n+\frac{\Delta t}{2}\rho^n\overline E\right).\]

Translate each column of f, of size (nv, nx), with second-degree semi-Lagrangian interpolation at acceleration $\overline E$. Update f and E in place and return E.

source
VlasovAmpereEnergyPreserving.hf_lapenta! — Function
hf_lapenta!(f, E, dt, dv, v, kx)

Advance $\partial_t f+v\partial_xf=0$ on a periodic spatial mesh by applying the Fourier multiplier $e^{-ikv\Delta t}$. Update f, of size (length(v), length(kx)), in place and return it. E is unchanged; dv is retained for compatibility with the calling interface.

VlasovAmpereEnergyPreserving.compute_diag — Function
compute_diag(f, Ex, Ey, B, rx, ry, mesh::Mesh1D2V, t)

Return a dictionary of mass, field norms, and energy diagnostics at time t. All integrals use uniform-grid sums over mesh:

\[\begin{aligned} K &= \frac12\int (v_x^2+v_y^2)f\,dx\,dv_x\,dv_y,\\ M &= \int f\,dx\,dv_x\,dv_y,\\ \mathcal H_{\mathrm{SAV}} &= K+r_x^2+r_y^2+\frac12\int B^2\,dx,\\ \mathcal H_{\mathrm{physical}} &= K+\frac12\int(E_x^2+E_y^2+B^2)\,dx. \end{aligned}\]

KineticEnergy and IntegralF contain $K$ and $M$. TotalEnergy1 and TotalEnergy2 contain the SAV and physical energies. BNorm, ExNorm, and EyNorm are squared spatial norms (without a factor of one half); RxSquare, RySquare, and time contain rx^2, ry^2, and t. No input arrays are modified.
